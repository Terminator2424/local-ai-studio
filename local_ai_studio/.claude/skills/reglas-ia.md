# Reglas del Proyecto Local AI Studio

Cuando trabajes en este proyecto, debes seguir estas reglas estrictas:
1. Todo el código nuevo debe tener comentarios en español explicando su función.
2. Si vas a crear un script de Python, asegúrate de manejar los errores con bloques `try/except` e imprimir logs claros.
3. No modifiques los archivos dentro de la carpeta `venv` ni `models`.
4. Antes de sugerir un cambio grande, explícame brevemente qué archivos vas a tocar.
